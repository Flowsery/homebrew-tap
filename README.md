# Flowsery Homebrew tap

```bash
brew trust Flowsery/tap
brew install Flowsery/tap/flowsery
```

Installs the standalone `flowsery` binary, with `fsy` as a shorter alias. No Node
required. Source and issues live at https://github.com/Flowsery/flowsery-cli.

`npm install -g @flowsery/cli` is the other way in, if you would rather have it as a
Node package.
